Vord 快速添加

选中英文词汇，右键选择「快速添加到 Vord」。检查释义后按 Return 保存。

安装与连接
  1. 打开本机 Vord，在 Settings → Selection & browser 选择 Chrome 或 Edge 后点击 Set up browser。
  2. 在 Chrome 或 Edge 扩展管理页开启「开发者模式」，点击「加载已解压的扩展程序」，选择 Vord 打开的 BrowserExtension 文件夹。

网页右键菜单由本扩展提供。Safari、文章和文本应用可使用系统「服务 → 快速添加到 Vord」。应用需要支持 macOS 服务。

选中的词只传给本机 Vord。
